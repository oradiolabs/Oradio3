# Design documents (historical)

was intended when they were written. Many no longer match the implementation.
Where a document and the code disagree, the code is right.

For the current behaviour, read:

- the docstrings and comments in `Main/`
- the [main README](../README.md) (installation, thresholds waiting on field data)
- the comments in `constants.env` and `install_resources/`
